# Christiaan Roukema

Portfoliowebsite voor Christiaan Roukema — handgemaakt houtwerk: meubels, kistjes, snijplanken en klussen.

Statische site, geen build-stap nodig: open `index.html` in de browser, of serveer de map met een simpele static server, bijvoorbeeld:

```
npx serve .
```

## Structuur

- `index.html` — de pagina
- `css/style.css` — styling
- `js/main.js` — menu + lightbox voor de projectfoto's
- `assets/img/` — logo (`logo-roukema.png`, origineel, transparante achtergrond) en projectfoto's
- `assets/favicon.svg`

## Nog te doen

- Contact: het e-mailadres in de contactsectie (`info@christiaanroukema.nl`) is een placeholder — vervang door het echte contactadres.
